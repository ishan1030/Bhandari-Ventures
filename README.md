# Crypto Hopper Lite

A lightweight cryptocurrency trading bot template.

## Features
- Paper trading mode (default)
- Simple Moving Average (SMA) crossover strategy
- Support for multiple exchanges via CCXT
- Easy to extend

## Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Configure your settings in `config.py`
4. Run the bot: `python main.py`

## Web Dashboard
The bot now includes a web dashboard for monitoring and control.
1. Start the bot with the web dashboard: `python run_with_web.py`
2. Open your browser and navigate to `http://localhost:5000`
3. Use the "Start Bot" and "Stop Bot" buttons to control the trading engine.
4. Monitor latest prices, signals, and trade history in real-time.
